财务分析学习笔记：从利润到现金，再到企业分析框架

一、总体思路

分析一家公司，先走两条路线：

1. 利润路线：看账上赚不赚钱，利润怎么分配；
2. 现金路线：看手上有没有真钱，钱怎么流动。

两条路线起点相同，都是净利润；终点不同：

- 利润路线终点：未分配利润；
- 现金路线终点：留存自由现金流。

一句话：

利润看账，现金看钱；利润是起点，现金是验证。

二、利润路线

1. 利润表主线

text

```
营业收入
- 营业成本
= 毛利润

- 销售费用
- 管理费用
- 研发费用
- 财务费用
= 营业利润

+ 营业外收支
= 利润总额

- 所得税
= 净利润
```



1. 利润分配路线

text

```
净利润
- 提取盈余公积
- 分红
= 未分配利润增加
```



1. 关键理解

- 毛利润：收入减去营业成本后的结果；
- 营业利润：毛利润减去四项费用后的结果；
- 利润总额：营业利润加上营业外收支；
- 净利润：利润总额减去所得税；
- 盈余公积：从净利润中提取，留在公司，不能随便分；
- 未分配利润：累计赚了但还没分掉的利润。

一句话：

利润路线更接近会计科目，终点是未分配利润。

三、现金路线

1. 从净利润到经营现金流

text

```
经营现金流 =
净利润
+ 折旧摊销
- 营运资本增加
+ 其他非现金调整
```



更完整地写：

text

```
经营现金流 =
净利润
+ 折旧摊销
- 应收账款增加
- 存货增加
- 预付款增加
+ 应付账款增加
+ 预收账款增加
+/- 其他营运资本变化
```



1. 从经营现金流到自由现金流

text

```
经营现金流
- 资本开支
= 自由现金流
```



1. 从自由现金流到留存自由现金流

text

```
自由现金流
- 分红
= 留存自由现金流
```



1. 关键理解

- 折旧：成本分期，不是现金流出；
- 经营现金流：日常经营真正收进来的钱；
- 资本开支：本年实际支付的长期资产支出；
- 自由现金流：经营现金流减去资本开支后，真正能自由支配的钱；
- 留存自由现金流：分完红后，真正留在公司手里的现金。

一句话：

现金路线更接近分析指标，终点是留存自由现金流。

四、从净利润到经营现金流：加减原理

1. 核心逻辑

从净利润推算经营现金流，核心是看：

利润确认和现金收付之间的时间差。

也就是：

- 哪些利润没收到现金；
- 哪些成本没付出现金；
- 哪些钱被占用；
- 哪些钱被释放。

一句话：

占用现金的项目要减，释放现金的项目要加。

1. 占用现金的项目：减

text

```
应收账款增加：减
存货增加：减
预付款增加：减
```



1. 释放现金的项目：加

text

```
应收账款减少：加
存货减少：加
应付账款增加：加
预收账款增加：加
```



1. 折旧摊销：加

text

```
折旧摊销：加
```



1. 完整逻辑

text

```
净利润
+ 折旧摊销等非现金费用
+/- 营运资本变化
= 经营现金流
```



1. 一句话记忆

净利润是账，经营现金流是钱。

应收、存货增加，钱被占用，减；
应付、预收增加，钱还没付或先收到，加；
折旧摊销没流出现金，加回来。

五、折旧的理解

1. 折旧是什么？

折旧是把长期资产的成本，按使用年限分摊到每年的成本费用。

- 买机器时：现金一次性流出；
- 以后每年：只分摊成本，不再流出现金。

1. 折旧为什么加回？

因为：

- 算净利润时，折旧被减掉了；
- 但当期现金并没有减少；
- 所以算经营现金流时，要把折旧加回来。

一句话：

折旧影响利润，不影响当期经营现金。

1. 折旧在利润表的位置

- 生产用固定资产折旧：通常进入营业成本，影响毛利润；
- 管理、销售用固定资产折旧：通常进入管理费用或销售费用，不影响毛利润，只影响营业利润和净利润。

六、净利润与经营现金流的关系

1. 会计上谁先谁后？

会计上：

- 先算净利润；
- 再编现金流量表；
- 两者分别编制，不是谁直接推导谁。

分析上：

- 为了看利润变现能力，常从净利润倒推经营现金流。

1. 经营现金流可能大于净利润

原因：

- 折旧加回；
- 应收账款收回；
- 存货减少；
- 应付账款增加。

1. 经营现金流可能小于净利润

原因：

- 应收账款增加；
- 存货增加；
- 营运资本占用现金。

1. 判断利润质量

text

```
净现比 = 经营现金流 / 净利润
```



长期 > 1：利润有现金支撑，质量较好；
长期 ≈ 1：正常；
长期 < 1：利润可能被应收、存货占用，质量差；
长期 < 0：经营现金流为负，风险大。

一句话：

经营现金流是利润变现的过程；长期低于净利润，说明盈利质量不高。

七、自由现金流与分红

1. 自由现金流

text

```
自由现金流 = 经营现金流 - 资本开支
```



含义：

公司维持经营和必要投资之后，真正能自由支配的钱。

1. 资本开支

- 本年实际支付的长期资产支出；
- 包括买设备、建厂房、买软件、买专利等；
- 不是“为未来预留的钱”，而是“本年已经花掉的钱”。

1. 分红

text

```
自由现金流
- 分红
= 留存自由现金流
```



一句话：

有利润，不一定有现金；有现金，才谈得上分红；有自由现金流，才谈得上持续分红。

八、资产负债表分析

1. 看什么

总资产：公司规模
总负债：债务压力
净资产：股东家底
资产负债率：负债水平
有息负债：真正要付利息的债
货币资金：手上现金
应收账款：回款能力
存货：周转能力
商誉：并购风险

1. 核心指标

text

```
资产负债率 = 总负债 / 总资产
有息负债率 = 有息负债 / 总资产
流动比率 = 流动资产 / 流动负债
速动比率 = (流动资产 - 存货) / 流动负债
```



一句话：

资产负债表回答：公司家底厚不厚，债多不多，能不能扛风险。

九、回报率分析

1. ROE：净资产收益率

text

```
ROE = 净利润 / 净资产
```



杜邦分解：

text

```
ROE = 净利润率 × 总资产周转率 × 权益乘数
```



净利润率：赚钱能力
总资产周转率：资产使用效率
权益乘数：杠杆水平

1. ROA：总资产收益率

text

```
ROA = 净利润 / 总资产
```



1. 判断标准

- ROE 长期 > 15%：优秀；
- ROE 高但靠高杠杆：要警惕；
- ROE 高且净利润率、周转率都好：质量高；
- ROA 高：资产效率高。

一句话：

回报率回答：公司赚钱效率高不高，是靠本事还是靠杠杆。

十、估值分析

1. PE：市盈率

text

```
PE = 股价 / 每股收益 = 总市值 / 净利润
```



含义：

市场愿意为公司每1元利润付多少钱。

1. PB：市净率

text

```
PB = 股价 / 每股净资产 = 总市值 / 净资产
```



含义：

市场愿意为公司每1元净资产付多少钱。

1. PEG：市盈率相对盈利增长比率

text

```
PEG = PE / 净利润增长率
```



含义：

用增长来调整估值。

一句话：

估值回答：好公司，现在价格贵不贵。

十一、实战分析框架

第一层：利润

- 收入是否增长？
- 毛利率是否稳定？
- 营业利润是否来自主业？
- 净利润是否真实？

第二层：现金

- 经营现金流是否为正？
- 经营现金流是否大于净利润？
- 自由现金流是否为正？
- 分红是否来自自由现金流？

第三层：资产负债

- 资产负债率高不高？
- 有息负债多不多？
- 货币资金是否覆盖短期债务？
- 应收账款、存货是否异常？

第四层：回报率

- ROE 是否长期 > 15%？
- ROE 是靠利润、周转还是杠杆？
- ROA 是否稳定？
- 留存利润有没有创造更高回报？

第五层：估值

- PE 处于历史什么位置？
- PB 是否合理？
- PEG 是否小于 1？
- 和同行比贵不贵？

十二、总图

text

```
营业收入
   │
   ▼
毛利润 → 营业利润 → 净利润
   │                   │
   │                   ├── 利润路线：盈余公积/分红/未分配利润
   │                   │
   │                   └── 现金路线：经营现金流 → 自由现金流 → 分红/留存
   │
   ▼
资产负债表：资产、负债、净资产
   │
   ▼
ROE / ROA：赚钱效率
   │
   ▼
PE / PB / PEG：估值贵不贵
```



十三、最核心的总结

利润看赚没赚，现金看真不真，负债看稳不稳，ROE看效率高不高，估值看贵不贵。

利润是起点，现金是验证，资产负债表是底线，ROE是质量，估值是价格。

分析顺序：

1. 利润路线；
2. 现金路线；
3. 资产负债表；
4. ROE / ROA；
5. PE / PB / PEG。

先跑通框架，再补细节。

十四、学习心态

- 造假存在，但不是不学财务分析的理由；
- 先学排除明显有问题的公司，再学识别复杂造假；
- 先跑通主干，再补枝叶；
- 先看正常公司，再看异常公司；
- 费劲是正常的，方向是对的。

一句话：

先跑通框架，再补细节；先排除明显问题，再深入复杂造假





***估值的底层逻辑：增长***

* 假如一块地没有产出，你会买下来耕种吗，假如一颗苹果树不结果子了，你会买下来等待收获吗。

* 假如一块地土质肥沃，年年高产，你自然会买下来辛勤耕种，假如一个果园土地肥沃，果树枝繁叶茂，苹果年年丰收，你一定会辛勤打理，等待来年的收获

  

***估值的简单理解和计算***

* 静态估值法： 假设公司的利润增长率是0（近几年每年都是相同的净利润额），那就按照公司的当前市值和年利润比值得出PE，比如10倍PE,那就是每年10%的收益率，10年收回投资成本。如果你是单纯的攒股收息投资者，平均5%的股息率，那么不采用分红复投的情况下需要20年才能收回本金，如果采用分红复投多攒股权的话，也许10年就能收回本金。

* PEG估值法： 在静态PE的基础上有了成长(`GROWTH:G`)，`PE  with  Growth`(这是自己的理解)，

  先记住结论，在净利润增长率值和PE相等时收回投资本金的年限为市场认可的合适年限：  

    PE/(GROWTH*100   =   1

  比如净利润增长率达到40%  ，那么PE=40   ;

  比如净利润增长率达到30%  ，那么PE=30   ;

  以此类推，至于PEG的原理和细节，看自己的另外一篇估值笔记：`估值：从 PE 到 PEG：一张回本表背后的估值逻辑`
