# 📒 醪糟（甜酒酿）制作完全笔记（完整版）

---

## 一、核心原理：双菌接力发酵

| 阶段                     | 主导菌                                   | 环境     | 主要工作                                                     | 产物                | 氧气需求         |
| :----------------------- | :--------------------------------------- | :------- | :----------------------------------------------------------- | :------------------ | :--------------- |
| **糖化期**（约0-36小时） | **根霉菌**（为主）<br>酵母菌（繁殖扩军） | **有氧** | 根霉菌分泌糖化酶，将淀粉分解为糖；酵母菌在有氧条件下优先繁殖，壮大种群 | 葡萄糖、麦芽糖、水  | **需要氧气**     |
| **酒化期**（约36小时后） | **酵母菌**（为主）<br>根霉菌（残余工作） | **无氧** | 酵母菌将糖转化为酒精和二氧化碳；根霉菌活性下降，但仍缓慢糖化 | 酒精、CO₂、香气物质 | **无氧环境更佳** |

### 🔬 关键理解
- **甜酒曲中同时含有根霉菌和酵母菌**，两种菌从一开始就一起被拌入糯米中。
- **有氧阶段**：根霉菌是主角，负责产甜；酵母菌是配角，主要繁殖（生孩子），不大量产酒。
- **无氧阶段**：酵母菌成为主角，开始高效地把糖转化为酒精；根霉菌活性被抑制，但未死亡。
- **换盖子的本质**：不是引入新菌种，而是**改变环境，让已经存在的酵母菌切换工作模式**（从繁殖 → 产酒）。

### ⚠️ 注意
两个阶段**不是严格先后**，而是有重叠。糖化约24-36小时后，酒化逐渐启动。糖化完成的标准是：**酒窝出满水，尝起来甜味明显**。

## 二、原材料

| 材料       | 用量参考（以500g干糯米为例） | 备注                                                 |
| :--------- | :--------------------------- | :--------------------------------------------------- |
| **圆糯米** | 500g                         | 圆糯米比长粒糯米饭更软糯，出酒率高                   |
| **甜酒曲** | 约2-4g（按包装说明）         | 传统土曲或现代纯种曲均可，**同时含有根霉菌和酵母菌** |
| **凉白开** | 适量                         | 用于化开酒曲、调节湿度、降温                         |

## 四、盖子选择指南（完整版）

###  糖化阶段（有氧，0-36小时）

| 盖子类型                            | 可用性             | 说明                                     |
| :---------------------------------- | :----------------- | :--------------------------------------- |
| **Masontops Kefir Cap（开启模式）** | ✅ **最佳**         | 透气可调，带过滤倒汁功能                 |
| **发芽罐盖子 + 一层干纱布**         | ✅ **推荐替代方案** | 网孔较大时用干纱布增加防护，透气性仍足够 |
| **纱布+橡皮筋**                     | ✅ 推荐             | 透气极好，防杂菌                         |
| **梅森细网发酵盖**                  | ✅ 推荐             | 透气+防尘，非常方便                      |
| **保鲜膜扎孔**                      | ✅ 可行             | 注意孔不要太小                           |
| **盖子虚掩（留缝）**                | ✅ 可行             | 缝隙要肉眼可见                           |
| **单独发芽盖（无纱布）**            | ⚠️ 可用但防虫较差   | 环境干净时可尝试，有果蝇时不推荐         |
| **完全敞口**                        | ❌ 不推荐           | 易进杂菌、表面干壳                       |
| **普通密封盖（拧紧）**              | ❌ 禁用             | 无氧环境，根霉菌无法工作                 |
| **单向阀盖子**                      | ❌ 禁用             | 无氧环境，根霉菌无法工作                 |

### 酒化阶段（无氧，36小时后）

| 盖子类型                       | 可用性             | 说明                             |
| :----------------------------- | :----------------- | :------------------------------- |
| **单向阀盖子（水封式）**       | ✅ **最佳**         | 注水后自动排气，传统经典         |
| **单向阀盖子（硅胶自动排气）** | ✅ **最佳**         | 一体式硅胶，无需加水维护，更省心 |
| **普通密封盖**                 | ⚠️ 可用但需手动放气 | 每天手动拧开排气，有爆瓶风险     |
| **Kefir Cap（关闭模式）**      | ❌ 不推荐           | 只是普通密封，不会自动排气       |
| **任何透气盖子**               | ❌ 禁用             | 氧气进入会导致酒化失败或发酸     |

###  最佳组合方案（一瓶到底，两盖分工）

| 阶段                 | 用什么盖子                         | 状态     | 环境         |
| :------------------- | :--------------------------------- | :------- | :----------- |
| 糖化（0-36小时）     | **Kefir Cap** 或 **发芽盖+干纱布** | 透气模式 | 有氧，28-32℃ |
| 糖化完成（尝到甜味） | 拧下糖化盖                         | —        | —            |
| 酒化（36小时后）     | **单向阀盖子**（水封或硅胶）       | 自动排气 | 无氧，20-28℃ |

> **瓶子不用换**，只需换盖子。梅森罐的螺纹是标准尺寸，两种盖子都能拧上。

###  替代方案详解：发芽罐盖子 + 一层干纱布

**适用场景**：手边没有Kefir盖或专业细网发酵盖，但有梅森罐发芽盖（Sprouting Lid，网孔较大）时。

| 组件           | 作用                               | 注意事项                                              |
| :------------- | :--------------------------------- | :---------------------------------------------------- |
| **发芽罐盖子** | 提供结构支撑，防止纱布塌陷或掉落   | 使用前用开水烫或酒精擦拭消毒                          |
| **一层干纱布** | 增加过滤精度，防止小飞虫和灰尘进入 | **必须用干纱布**（不要湿），使用前消毒（蒸/煮后晾干） |

**组装步骤**：
1. 纱布消毒后晾干（或轻轻拧干不滴水）
2. 将干纱布平铺在瓶口
3. 拧上发芽盖，压住纱布，确保平整不塌陷
4. 若果蝇较多，可用两层干纱布或橡皮筋加固

**为什么用干纱布而不是湿纱布？**
- 干纱布透气性更好
- 不会吸水导致米粒表面变干
- 不会因潮湿而滋生杂菌

## 五、制作流程（分步详解）

### 第1步：泡米
- 糯米淘洗2-3次，加足量清水浸泡
- **夏季**：浸泡4-6小时
- **冬季**：浸泡8-12小时
- 判断标准：米粒能用手指**碾碎**即可

### 第2步：蒸米
- 蒸笼铺纱布，沥干的糯米均匀铺开
- 用筷子扎几个**透气孔**
- 上汽后**中火蒸30-40分钟**
- 判断标准：米粒**透明、熟透、无白芯、粒粒分明不粘连**

### 第3步：降温
- 将蒸好的米饭摊开在干净容器中
- 用饭勺翻拌散热，降至**30-35℃**（手摸不烫、温热）
-  温度过高会烫死菌种，过低则发酵启动慢

### 第4步：拌曲
- 取甜酒曲，用**凉白开**化开（或直接撒粉）
- 将曲水/曲粉均匀拌入米饭中，确保每粒米都沾到
- 中间用勺子挖一个**直达底部的酒窝**（观察出酒）

### 第5步：装罐糖化（第一阶段，约24-36小时）

| 项目         | 设置                                                 |
| :----------- | :--------------------------------------------------- |
| **容器盖法** | Kefir Cap（开启模式）或 发芽盖+干纱布 或 纱布+橡皮筋 |
| **温度**     | 28-32℃（最佳30℃）                                    |
| **环境**     | 避光、温暖、无风                                     |
| **判断完成** | 酒窝出满液体、米粒变软、尝起来**甜味明显**           |

> 糖化阶段酵母菌在做什么？——在有氧环境下**繁殖扩军**，为下一阶段做准备。

### 第6步：换盖酒化（第二阶段，可选）

当糖化完成、尝到甜味后：

| 目的                     | 操作                                                         |
| :----------------------- | :----------------------------------------------------------- |
| **只做醪糟（停止发酵）** | 换不换盖均可，直接放入**冰箱冷藏**（4℃），可保存1-2周        |
| **继续做米酒（酒化）**   | ① 可加凉白开（米：水≈1:1.5）<br>② **拧下糖化盖，换上单向阀盖子**（水封或硅胶自动排气盖）<br>③ 温度20-28℃，发酵3-7天至想要的酒味 |

> 换盖后发生了什么？——氧气被消耗，酵母菌被迫切换代谢路径，开始**高效地把糖转化为酒精和CO₂**。

## 六、环境控制

| 因素         | 糖化阶段（0-36h）                      | 酒化阶段（36h后）  |
| :----------- | :------------------------------------- | :----------------- |
| **温度**     | 28-32℃                                 | 20-28℃             |
| **氧气**     | 需要（有氧）                           | 无氧更佳           |
| **湿度**     | 保持湿润，表面不干                     | —                  |
| **避光**     | 避光或弱光                             | 避光或弱光         |
| **盖子状态** | 透气盖（Kefir开启/纱布/发芽盖+干纱布） | 单向阀盖子自动排气 |

### 🔄 换盖时机（关键）
- **不要按死时间换盖**，要以状态为准：
  - ✅ 酒窝出满液体
  - ✅ 米粒变软
  - ✅ 尝起来**甜味明显**
- 达到以上状态后，即可**拧下糖化盖，换上单向阀盖子**

###  维持温度的方法

| 方法            | 说明                                             |
| :-------------- | :----------------------------------------------- |
| **恒温设备**    | 米酒发酵机、多功能发酵机、家用发酵箱             |
| **温水浴法**    | 大容器装35-40℃温水，放入发酵罐，8-12小时换一次水 |
| **温控插座DIY** | 温控插座 + 电热毯/旧酸奶机/电饭煲/泡沫箱         |
| **自然温度**    | 夏季室温、暖气片旁、灶台边                       |

## 七、常见现象判断

| 现象                     | 判断               | 原因/处理                                        |
| :----------------------- | :----------------- | :----------------------------------------------- |
| 酒窝出水，液体清澈，味甜 | ✅ 正常糖化         | 根霉菌工作良好，继续或转入酒化                   |
| 有酒味但完全不甜         | ⚠️ 糖化不足         | 可能缺氧（盖子太密封）或温度不当，根霉菌没产够糖 |
| 表面长白毛/绿毛/黑毛     | ❌ 杂菌污染         | 直接丢弃，不可食用                               |
| 液体浑浊，有酸味/馊味    | ❌ 杂菌感染         | 醋酸菌等占优，丢弃                               |
| 出水极少或不出水         | ⚠️ 糖化弱           | 检查温度、酒曲活性、盖子是否太密封               |
| 大量冒大泡，米粒塌陷     | ⚠️ 过度酒化或杂菌   | 需在甜味阶段及时换盖/冷藏                        |
| 酒味纯正但不够甜         | 正常（偏干型米酒） | 糖分被酵母充分转化，适合做米酒，不适合做醪糟     |

## 八、成功关键要点（完整版）

1. **无菌操作**：所有器具**无油无水**，可用开水或高度白酒消毒
2. **温度精准**：糖化28-32℃，温度计比手感更可靠
3. **糖化必须透气**：不能用密封盖或单向阀
4. **以口感为准**：不要死守时间，尝到甜味再转酒化或冷藏
5. **凉白开全程使用**：所有接触水都需煮沸后冷却
6. **理解双菌接力**：甜酒曲同时含根霉菌和酵母菌——有氧阶段根霉菌产甜、酵母菌繁殖；无氧阶段酵母菌产酒。换盖不是引入新菌，而是**改变环境让酵母菌切换工作模式**
7. **一瓶到底，两盖分工**：糖化用透气盖（Kefir盖/发芽盖+干纱布/纱布），酒化用单向阀盖，不用换瓶子
8. **没有专业工具时的替代方案**：**发芽罐盖子 + 一层干纱布**，效果接近专业发酵盖
